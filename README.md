## My Contribution – Backend, Database & Integration

My contribution to WAYMATE focuses on backend development, database management, and integrating backend services with the application.

### Backend Development
- Developed backend functionality using Python and Flask.
- Created and connected API endpoints to support frontend operations.
- Implemented user authentication and backend services for destinations, saved places, and trip management.

### Database Management
- Designed and managed the MySQL database for storing user, destination, saved-place, and trip information.
- Connected the Flask backend with MySQL.
- Implemented database operations to insert, retrieve, update, and delete application data.

### Weather and Maps Integration
- Worked on integrating weather-related functionality into the application.
- Connected weather information with destination details.
- Worked on maps integration to support destination-related travel information.
